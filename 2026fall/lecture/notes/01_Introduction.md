# 01 · Introduction to Machine Learning（机器学习导论）

> 主来源：[Introduction.pdf](../Introduction.pdf)，PDF 页码从封面起算。本讲义以该课件的符号和主题为主线；凡课件未展开而这里补出的推导、例子或限制，标为 **【补充理解】**。

## 0. 这节课到底在解决什么问题？

假设你要判断一辆尚未见过的车是否适合家庭使用。你可以让人逐条编写规则，但“适合”的判断会涉及价格、空间、动力等特征，规则可能复杂且随市场变化。机器学习（Machine Learning, ML）尝试从带有结果的例子中找出一个可用于**新例子**的规则。课件用“性能相对某个标准，借助例子或过去经验得到改善”来界定 ML。（PDF p.4–7）

这句话里有三个不能省略的问题：**学什么任务？凭什么数据学？怎样判断学得好？** 在已有车辆上答对，只说明模型记住了训练样本；在未来车辆上仍答得对，才涉及泛化（generalization）。课件用多项式拟合和矩形分类两个例子，把这条主线从直觉推进到数学。（PDF p.20–50）

本节的可检验目标：读完后，能给一个问题区分输入与输出、模型与参数、训练误差与泛化误差；能从多项式模型推到最小二乘的正规方程；能解释为什么“训练误差为零”不足以选模型。

## 1. 前置知识和记号

只需要会函数、求和、导数、向量内积与基本概率。若梯度或矩阵维度不熟，先读 [Linear Algebra](02_Linear_Algebra.md)；若不清楚随机噪声与分布，先读 [Probability and Statistics](03_Probability_Statistics.md)。第一遍可以先读至第 3 节，再回头推第 4 节。

课件沿用两套紧邻的记号，务必分清：

| 场景 | 输入、输出 | 数据集 | 模型 |
|---|---|---|---|
| 曲线拟合（PDF p.20–32） | \(x_n\in\mathbb R\)、\(y_n\in\mathbb R\) | \(\{(x_n,y_n)\}_{n=1}^N\) | \(h(x,w)\)，\(w\in\mathbb R^{M+1}\) |
| 汽车分类（PDF p.35–43） | \(x^t\in\mathbb R^d\)、\(y^t\in\{0,1\}\) | 课件记 \(X=\{(x^t,y^t)\}_{t=1}^N\) | \(h\in\mathcal H\) |
| 回归概述（PDF p.45） | \(x^t\in\mathbb R^d\)、\(y^t\in\mathbb R\) | 同上 | \(h(x^t)\) |

\(N\) 是样本数，\(d\) 是特征数，\(M\) 是多项式最高次数。课件在分类例子中用 \(X\) 表示**整个样本集合**；下面为了推导最小二乘，另用 \(\Phi\) 表示设计矩阵，避免把集合和矩阵混在一起。上标 \(t\) 是样本编号，不是向量转置；转置明确写作 \(\mathsf T\)。

## 2. 核心直觉：从例子学规则，而不是背例子

### 2.1 什么情形需要学习？

有时专家规则编写成本高，有时没人能给出完整规则，有时专家会判断却难以解释，有时规则随时间变化；这些都是课件给出的应用动机。（PDF p.6）机器学习假设数据产生过程有一定规律，因此可用有限样本建立有用的近似模型。模型无需成为世界的完整复制品；它可以侧重描述规律，也可以侧重预测。（PDF p.7）统计学帮助我们处理“由样本推断总体”，计算机科学帮助我们设计计算、时间与空间成本可接受的算法。（PDF p.8）

**【补充理解：地图类比】** 模型像地图：道路位置对应数据中的规律；地图的比例尺和符号选择对应模型假设；按图导航对应在新输入上预测。类比只说明“有用的简化”，不能推出“地图越详细越好”：地图把施工中的临时障碍也画成永久道路，反而会误导，这类似过拟合。

机器学习和 signal processing（信号处理）、data mining（数据挖掘）、data science（数据科学）有交叉，但课件没有把它们当成同义词：data mining 偏向把 ML 方法用于大型数据库，data science 的范围还包括统计和可视化等。（PDF p.4–5）

### 2.2 四种任务，区别在“给了什么反馈”

课件先介绍 association rules（关联规则）。例如 \(P(\text{chips}\mid\text{beer})=0.7\) 是“买啤酒的人中，买薯片的比例为 70%”；加入顾客属性 \(D\) 可研究 \(P(Y\mid X,D)\)。这表示条件关联，**不能仅凭它断定买啤酒导致买薯片**。（PDF p.10–11）

supervised learning（监督学习）给每个训练输入一个目标输出。输出是离散类别时称 classification（分类），如依收入和储蓄区分信贷风险；输出是连续数值时称 regression（回归），如由二手车属性预测价格 \(y=g(x\mid\theta)\)。同样的监督规则还可用于知识提取、压缩和识别异常例子。（PDF p.12–16）

unsupervised learning（无监督学习）没有对应的目标标签，常做 density estimation（密度估计）、dimensionality reduction（降维）或 clustering（聚类）。因为未指定“标准答案”，评价方式通常不如监督任务直接。（PDF p.17）reinforcement learning（强化学习）则通过行动和延迟奖惩学习 policy（策略），需要处理探索与利用、把奖励归因于先前行动等问题。（PDF p.18）课件在 p.10 提到半监督、自监督、多任务、多标签等范式，但说明本入门课程不展开这些主题。

## 3. 正式定义：模型、损失、训练与泛化

### 3.1 三件事构成一个监督学习方法

课件最后把监督学习算法拆为三维（PDF p.52）：

1. **model（模型）**：\(h(x\mid\theta)\) 规定可用哪些预测函数；\(x\) 是输入，\(\theta\) 是要学习的参数。
2. **loss/error function（损失或误差函数）**：\(L(y^t,h(x^t\mid\theta))\) 衡量第 \(t\) 个预测的代价，\(E(\theta\mid X)=\sum_t L(\cdot)\) 汇总训练集的代价。
3. **optimization procedure（优化过程）**：\(\theta^*=\arg\min_\theta E(\theta\mid X)\) 指定怎样寻找使训练目标最小的参数。\(\arg\min\) 给出取得最小值的**参数**，不是最小值本身。

不同模型即使使用同一种优化算法，也可能作出不同预测；同一种模型换了损失，也会追求不同的“好”。课件的 no free lunch（没有普遍最优算法）提醒我们依数据与任务选择方法，而不是寻找一个对所有问题都最好的算法。（PDF p.52）

### 3.2 经验误差和真正关心的误差

在分类例子中，真实类规则记为 \(C(x)\)，但学习者通常只看见有限的标签 \(y^t\)，无法在所有可能的车上直接比较 \(h(x)\) 与 \(C(x)\)。课件用零一损失写经验错误数（empirical error）：

\[
E(h\mid X)=\sum_{t=1}^{N}\mathbf 1[h(x^t)\ne y^t],
\]

其中 \(\mathbf 1[\cdot]\) 在括号内命题为真时等于 1，否则等于 0。若除以 \(N\)，才是训练错误**率**。回归例子采用平均平方误差 \(E(h\mid X)=\frac1N\sum_t(y^t-h(x^t))^2\)；平方损失只是可选损失之一。（PDF p.39、45）

**【补充理解】** 若未来数据与训练数据来自相同的未知分布 \(P(x,y)\)，真正关心的可以形式化为 \(R(h)=\mathbb E_{(x,y)\sim P}[L(y,h(x))]\)。训练集上的 \(E\) 只是对这个未知量的有限样本观察。该表述是对课件“generalization”概念的数学补充；若未来分布改变，这一前提就不成立。

## 4. 数学推导：从多项式拟合到最小二乘

### 4.1 问题和模型

课件生成示意数据的方式是 \(y=\sin(2\pi x)+\text{noise}\)：我们只见有限的 \((x_n,y_n)\)，想预测新 \(x\) 的 \(y\)。（PDF p.20）假设可选函数是 \(M\) 阶多项式：

\[
h(x,w)=w_0+w_1x+\cdots+w_Mx^M=\sum_{j=0}^{M}w_jx^j.
\]

\(w_j\in\mathbb R\) 是系数，\(w\in\mathbb R^{M+1}\)。当 \(M>1\) 时 \(h\) 对输入 \(x\) 是非线性的，但在**固定输入后**对参数 \(w\) 是线性的；这就是课件称它为 linear model 的原因。（PDF p.21）例如 \(w_2x^2\) 中，\(x^2\) 是一个已计算好的特征，未知量仍只以一次幂出现。

### 4.2 为什么用平方误差？

课件度量每个点到预测曲线的**竖直差** \(h(x_n,w)-y_n\)，并最小化

\[
E(w)=\frac12\sum_{n=1}^{N}\big(h(x_n,w)-y_n\big)^2.
\]

平方使正负残差不会互相抵消，且大误差受到更重惩罚。前面的 \(1/2\) 只为抵消求导时的 2，不改变最优参数。竖直差与“点到曲线的最短欧氏距离”不同；这里是在给定 \(x_n\) 的条件下预测 \(y_n\)。（PDF p.22）

### 4.3 【补充理解：课件 p.22 未展开的闭式解】

**推导目标。** 求最小化 \(E(w)\) 的系数向量 \(w\)。

**已知条件。** 定义特征向量 \(\phi(x)=(1,x,\ldots,x^M)^\mathsf T\in\mathbb R^{M+1}\)；把第 \(n\) 个 \(\phi(x_n)^\mathsf T\) 放入矩阵第 \(n\) 行，得到 \(\Phi\in\mathbb R^{N\times(M+1)}\)。令 \(y=(y_1,\ldots,y_N)^\mathsf T\in\mathbb R^N\)，则 \(\Phi w\in\mathbb R^N\) 正好是全部训练预测。假定样本数和数据足以使 \(\Phi\) 列满秩，下面才可写唯一的逆矩阵解。

**Step 1：改写目标。** 因为欧氏范数平方等于每个分量平方之和，

\[
E(w)=\tfrac12\|\Phi w-y\|_2^2
=\tfrac12(\Phi w-y)^\mathsf T(\Phi w-y).
\]

**Step 2：展开。** 按矩阵乘法的分配律、\((\Phi w)^\mathsf T=w^\mathsf T\Phi^\mathsf T\)，以及标量等于其转置，

\[
E(w)=\tfrac12w^\mathsf T\Phi^\mathsf T\Phi w
-w^\mathsf T\Phi^\mathsf T y+\tfrac12y^\mathsf T y.
\]

**Step 3：逐项求梯度。** \(\Phi^\mathsf T\Phi\) 是对称矩阵，故第一项的梯度为 \(\Phi^\mathsf T\Phi w\)；第二项为 \(-\Phi^\mathsf T y\)；第三项不含 \(w\)，梯度为 0。于是

\[
\nabla_w E(w)=\Phi^\mathsf T\Phi w-\Phi^\mathsf T y
=\Phi^\mathsf T(\Phi w-y).
\]

这里 \(\Phi^\mathsf T(\Phi w-y)\) 的维度是 \((M+1)\times N\) 乘 \(N\times1\)，结果为 \((M+1)\times1\)，与 \(w\) 相同。

**Step 4：令梯度为零。** 对无约束、可微且凸的平方误差问题，一阶条件给出正规方程（normal equations）

\[
\Phi^\mathsf T\Phi w^*=\Phi^\mathsf T y.
\]

若 \(\Phi\) 列满秩，\(\Phi^\mathsf T\Phi\) 正定且可逆，因此 \(w^*=(\Phi^\mathsf T\Phi)^{-1}\Phi^\mathsf T y\)。若不满秩，预测的最小平方误差仍可达到，但系数可能不唯一；可用伪逆等方法找一个解。实际数值计算通常避免显式求逆。

### 4.4 【补充理解：正则化为何改变解】

课件把系数惩罚加入目标（PDF p.28）：

\[
\widetilde E(w)=\tfrac12\|\Phi w-y\|_2^2+\tfrac\lambda2\|w\|_2^2,
\qquad \lambda\ge0.
\]

\(\lambda\) 是 regularization parameter（正则化参数），\(\|w\|_2^2=\sum_{j=0}^M w_j^2\)。求导时第一项仍是 \(\Phi^\mathsf T(\Phi w-y)\)；第二项按 \(\partial(w_j^2/2)/\partial w_j=w_j\) 得 \(\lambda w\)。所以

\[
\nabla_w\widetilde E=\Phi^\mathsf T\Phi w-\Phi^\mathsf T y+\lambda w=0,
\qquad
(\Phi^\mathsf T\Phi+\lambda I)w^*=\Phi^\mathsf T y.
\]

当 \(\lambda>0\) 时，\(\Phi^\mathsf T\Phi+\lambda I\) 正定，解唯一。\(\lambda\) 小时主要追求训练拟合；过大时所有系数被推向零，可能欠拟合。这里严格沿用课件 \(\|w\|^2\)，包含常数项 \(w_0\)；有些实现不惩罚截距，做题时需看清约定。

## 5. Numerical Example：让公式落到数字上

### 5.1 最小二乘手算

**【补充理解】** 取三点 \((0,1),(1,2),(2,2)\)，用一阶模型 \(h(x)=w_0+w_1x\)。则

\[
\Phi=\begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix},\quad
y=\begin{bmatrix}1\\2\\2\end{bmatrix},\quad
\Phi^\mathsf T\Phi=\begin{bmatrix}3&3\\3&5\end{bmatrix},\quad
\Phi^\mathsf T y=\begin{bmatrix}5\\6\end{bmatrix}.
\]

正规方程为 \(3w_0+3w_1=5\)、\(3w_0+5w_1=6\)。两式相减得 \(2w_1=1\)，故 \(w_1=1/2\)；代回得 \(w_0=7/6\)。三个预测分别是 \(7/6,5/3,13/6\)，残差分别是 \(1/6,-1/3,1/6\)；它们乘以对应的 \(1,x_n\) 后求和均为零，正好核查 \(\Phi^\mathsf T(\Phi w-y)=0\)。平方误差和是 \(1/6\)，课件定义的 \(E=1/12\)。

### 5.2 正则化的最小例子

**【补充理解】** 用两点 \((0,1),(1,3)\) 拟合直线：不加惩罚可得到 \(w=(1,2)^\mathsf T\)，两点都恰好拟合。若沿用课件对全部系数惩罚并取 \(\lambda=1\)，则

\[
(\Phi^\mathsf T\Phi+I)w
=\begin{bmatrix}3&1\\1&2\end{bmatrix}w
=\begin{bmatrix}4\\3\end{bmatrix},
\]

解为 \(w=(1,1)^\mathsf T\)。第二点的预测由 3 变为 2，训练误差增加了，但系数规模下降了。这展示正则化的**取舍**；不能从这两个点断言新数据误差一定下降。

## 6. 两组图到底在说明什么？

### 6.1 曲线拟合图：容量、数据量与正则化

PDF p.23 的四个小图横轴是 \(x\)，纵轴是输出；蓝圈是带噪声样本，绿线是生成规律，红线是拟合结果。\(M=0,1\) 过于僵硬，\(M=3\) 能跟随主要趋势，\(M=9\) 在少量样本上急剧弯曲。红线穿过训练点不等于靠近绿线。

PDF p.24 的横轴是阶数 \(M\)，纵轴是 \(E_{\rm RMS}=\sqrt{2E(w^*)/N}\)；蓝线为训练误差，红线为测试误差。由于 \(2E\) 正是残差平方和，此式就是均方误差的平方根。图中高阶模型的训练误差接近零，测试误差却在 \(M=9\) 跃升：这是 overfitting（过拟合）的直接证据，不是“高阶模型数学上错误”。

PDF p.25 的系数表显示 \(M=9\) 的某些 \(w_j\) 达到很大绝对值；这解释了红线为何可能剧烈摆动。系数大小还受特征尺度影响，因此不能只凭“大系数”一项诊断所有过拟合。PDF p.26–27 对比 \(N=15\) 和 \(N=100\)：更多覆盖输入范围的数据让同一高阶模型较难随意穿过噪声，但数据增加不是万能保证。PDF p.46 又以里程预测价格展示一次、二次、六次模型的形状差异。

PDF p.29–30 固定九阶模型，比较 \(\ln\lambda=-18\) 与 \(\ln\lambda=0\)：后者惩罚强得多，红线接近平坦，说明过度正则化也会损失有用结构。PDF p.31 的横轴为 \(\ln\lambda\)，纵轴为 RMS 误差，测试曲线在中间较低、两端较高；p.32 的表显示系数随惩罚增强而缩小。图中标注的是 **test** 曲线，实际挑 \(\lambda\) 应使用验证集，不应反复利用最终测试集。

### 6.2 家庭用车图：假设空间与容量

PDF p.37 的横轴是价格 \(x_1\)，纵轴是发动机功率 \(x_2\)；蓝色矩形是由四条边 \(p_1,p_2,e_1,e_2\) 指定的“家庭用车”规则，正负标记是训练样本。数学上，矩形内同时满足 \(p_1\le x_1\le p_2\) 与 \(e_1\le x_2\le e_2\)。p.38 把全部可选矩形称为 hypothesis class（假设类）\(\mathcal H\)，一个具体矩形才是一个 hypothesis（假设）\(h\)。

PDF p.39–40 的关键问题是：可能有多个矩形把已知样本全分对，但它们在空白区域的预测不同。p.40 用紧的 \(S\) 和更宽的 \(G\) 画出 version space（版本空间）的直觉，即与训练样本一致的候选规则集合。**【补充理解】** 对一般数据，按矩形包含关系组织的版本空间未必只有唯一的一对 \(S,G\) 边界；应把这幅图作为示意，而把“所有与样本一致的 \(h\in\mathcal H\)”作为一般定义。

PDF p.41 的图中每个青色矩形代表针对某种正负标记选出的规则，不是一个最终训练出的模型。它引出 shatter（打散）：若一组点的所有 \(2^N\) 种二元标记都能由某个 \(h\in\mathcal H\) 实现，\(\mathcal H\) 就打散这组点。VC dimension（VC 维）是可打散点数的最大值。课件给出二维轴对齐矩形的 VC 维为 4。

**【补充理解：为什么是 4】** 取上、下、左、右四个点，任何指定为正的子集都能用一个轴对齐矩形包住而排除其余点，因此至少为 4。任取五点，挑出使横纵坐标达到最小和最大的至多四个点；必有第五点处在它们的包围盒内。把这些极值点标正、第五点标负，任何包含全部正点的轴对齐矩形也会包含第五点，所以不能打散任意五点，至多为 4。这个证明是课件结论的补充展开。

## 7. 为什么这对后面的 Machine Learning 很重要？

分类问题让我们看到：同样的训练错误数可以对应许多不同规则。回归问题也一样：多个函数可经过少量观测点，却在未知位置给出截然不同的值。因此要选择 hypothesis class（允许的模型集合）、损失和复杂度约束，这些选择构成 inductive bias（归纳偏置）。课件 p.48 的“矩形”与“线性函数”都是归纳偏置实例；它不是一定错误的偏见，而是从有限样本推向未见数据所必需的假设。

课件 p.48–49 区分 underfitting（欠拟合）与 overfitting（过拟合），并提出模型复杂度、样本数和泛化误差的三方关系。可把它理解为：复杂度不足时抓不住真实规律；复杂度过高而样本有限时容易适配偶然噪声；更多有代表性的样本通常有助于区分规律与噪声。这是**趋势与条件性的直觉**，不是 \(N\) 一增大、误差就对每个数据集严格下降的定理。

为估计泛化，课件 p.50 把数据分为 training、validation、test，并以 50%/25%/25% 作示例比例：训练集拟合 \(w\)；验证集选阶数 \(M\)、惩罚 \(\lambda\) 等设置；测试集只在选择完成后做最终评估。比例不是固定规定。数据少时可使用 resampling（重采样）；具体做法将在后续模型评估内容中展开。

## 8. 容易混淆的概念

| 概念 A | 概念 B | 真正差别 |
|---|---|---|
| classification | regression | 目标分别是离散类别和数值；不是按所用算法名称区分。 |
| model \(h(\cdot\mid\theta)\) | parameter \(\theta\) | 前者规定函数形式，后者给定某个具体函数。 |
| hypothesis \(h\) | hypothesis class \(\mathcal H\) | 前者是一条规则，后者是候选规则集合。 |
| empirical error | generalization error | 前者在已见样本上算，后者关心未来样本。 |
| \(M\) 与 \(w\) | \(\lambda\) | \(M\) 决定多项式可表达的阶数；\(w\) 是拟合出的系数；\(\lambda\) 决定系数惩罚强度。 |
| validation set | test set | 前者参与模型选择，后者留给选定模型后的最终估计。 |
| overfitting | underfitting | 前者对训练细节过敏，后者表达能力或拟合程度不足；都可能使新数据表现差。 |

## 9. 常见错误与边界

1. “\(M=9\) 能过全部点，所以最好。”只说明训练误差小；看 PDF p.24 的测试曲线才能发现问题。
2. “多项式是曲线，所以不是线性模型。”课件的 *linear* 指对参数 \(w\) 线性，不一定对原始输入 \(x\) 线性。（PDF p.21）
3. “有了零训练误差就找到了真实类 \(C\)。”p.39–40 展示多个一致假设可在未观察区域相互矛盾。
4. “在 test 上试很多次，选最好的一次。”这样 test 已参与选择，不能再当独立的最终评估。
5. “关联规则说明因果。”\(P(Y\mid X)\) 描述条件关系；要断言因果还需其他设计和假设。
6. “VC 维 4 表示只能处理四个训练点。”VC 维描述可实现标记模式的容量，并非可用样本数上限。（PDF p.41）
